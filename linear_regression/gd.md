# Gradient Descent — 笔记

## 一、核心定义

#### 梯度下降 (gradient descent)

一种迭代式最优化算法，用于最小化函数 $J(\mathbf{w})$ 。

- **一维版本**：从初始猜测 $w_0$ 出发，重复应用更新规则

$$
w\leftarrow w-\alpha J'(w)
$$

直到满足停止条件。

- **一般（向量）版本**：

$$
\mathbf{w}\leftarrow\mathbf{w}-\alpha\nabla_{\mathbf{w}}J(\mathbf{w})
$$

所有分量**同时**更新（不能一个坐标接一个坐标地更新，否则后面的偏导会用到已改变的权重）。

#### 迭代 (iteration)

每应用一次更新规则称为一次迭代。

#### 学习率 (learning rate) $\alpha\in\mathbb{R}$

控制每步更新幅度的超参数，典型取值在 $0.001$ 到 $0.1$ 之间，需按具体问题调优。

#### 训练曲线 (training curve)

训练代价随迭代次数变化的曲线，用于监控梯度下降是否收敛、诊断学习率是否合适。

#### 局部最小值 (local minimum) / 全局最小值 (global minimum)

梯度下降只利用局部信息，因此只能保证找到局部最小值；不同初始化可能收敛到不同的局部最小值。但线性回归的均方误差是**凸函数 (convex)**（碗状二次函数），只有一个最小值，因此梯度下降一定能找到全局最小值。

#### 特征缩放 / 标准化 (feature scaling / standardization)

训练前将各特征化为可比较的量纲（如减均值除以标准差），避免损失曲面呈"峡谷状 (ravine)"导致优化路径来回震荡 (zig-zag)。

## 二、公式

线性回归的梯度下降更新规则：

$$
\mathbf{w}\leftarrow\mathbf{w}-\frac{\alpha}{N}\mathbf{X}^\top(\mathbf{X}\mathbf{w}-\mathbf{t})
$$

其中 $\mathbf{w}\in\mathbb{R}^{(D+1)\times1}$ （含偏置）、 $\alpha>0$ 为学习率、 $\mathbf{X}\in\mathbb{R}^{N\times(D+1)}$ 为设计矩阵、 $\mathbf{t}\in\mathbb{R}^{N\times1}$ 为目标向量。

方向导数 (directional derivative)： $J$ 在 $\mathbf{w}$ 处沿单位方向 $\mathbf{u}$ 的方向导数为 $D_{\mathbf{u}}J(\mathbf{w})=\nabla J(\mathbf{w})\cdot\mathbf{u}$ ，在所有单位向量中，当 $\mathbf{u}$ 与 $\nabla J(\mathbf{w})$ 同向时该内积最大——这正是"梯度方向为最速上升方向"的依据。

## 三、推导 / 论证过程

**更新方向的确定**：对比最小值两侧的点——最小值左侧导数为负（应向正方向移动），右侧导数为正（应向负方向移动），归纳出**下降方向 = 梯度符号的反方向**，因为梯度指向最速上升方向，其反方向即最速下降方向。

**步长大小的确定**：离最小值远的点（曲线陡）导数值大，离最小值近的点（曲线平）导数值小；由于最小值处导数恰为 0，合理的做法是让更新幅度正比于梯度大小——这样自然实现"离得远走得快、离得近走得慢、到达处自动停止变化"。

**几何事实（不加证明）**：梯度 $\nabla_{\mathbf{w}}J$ 总是与等高线 (contour line) 垂直；因为梯度下降沿 $-\nabla_{\mathbf{w}}J$ 方向移动，所以每一步都与等高线垂直相交，始终指向最速下降方向。

## 四、方法论：使用梯度下降的关键考量

1. **学习率选择**：
   - $\alpha$ 太小 → 收敛慢，需要很多次迭代。
   - $\alpha$ 太大 → 可能越过最小值导致发散（新点梯度比原来更大，越走越远）。
   - 实践中通过观察**训练曲线**来经验性地选择 $\alpha$ 。
2. **停止条件**：理论上应等参数收敛（ $\mathbf{w}$ 几乎不再变化），但高维时难以追踪；实践中常改为监控**训练代价是否收敛**（代价提升低于某阈值即停止），或直接设定**固定迭代次数**（受时间/资源限制时）。
3. **局部 vs 全局最小值**：一般模型只能保证局部最优；但线性回归+平方损失是凸问题，梯度下降迭代足够多次必达全局最优。
4. **特征缩放**：
   - 若某特征量纲远大于其他特征（如一个是几百、另一个是千分之几），其偏导数会被放大很多倍（如相差十万倍），损失曲面变成狭长峡谷，梯度下降在陡峭方向反复震荡，在平坦方向前进缓慢；标准化（减均值除标准差）可以把损失曲面变得更"圆"，改善收敛速度（只需标准化输入特征，目标值 $\mathbf{t}$ 不需要）。
   - 但即使标准化后，若两个特征**高度相关**（几乎测量同一个量），它们的权重仍会几乎等价地相互替代，损失曲面会变成沿 $w_1=w_2$ 对角线方向的旋转峡谷，梯度下降依然会震荡——说明标准化不能完全解决所有病态几何问题。

## 五、核心概念与思想

- **Idea #1（学习即优化）**：直接解只在损失代数上可解时可用；梯度下降是通用策略，只要损失可微就适用，不依赖闭式解是否存在。
- **Idea #4（ML 描述几何过程）**：全篇贯穿几何直觉——1D 函数图像、2D 等高线图（contour plot）；梯度垂直于等高线，损失曲面的形状（圆碗、狭长峡谷、旋转椭圆）直接决定收敛快慢；特征缩放本质是把损失曲面"整形"得更圆，是一种几何干预。
- **权重空间 (weight space)** 视角：权重空间中的每一点对应一个具体假设（输入到输出的映射）；优化过程 = 在权重空间中不断移动到"更好"的邻近假设。

## 六、例子（精简保留）

- **雾中下山比喻**：站在山顶，看不清全局，只能凭脚下坡度判断方向、一步步往下走，直到走到谷底（车所在处）——这正是梯度下降"仅用局部信息迭代逼近最小值"的直觉来源。
- **量纲失衡例子**（原文出自 "5.4 Feature scaling" 一节；"量纲失衡"本身并非原文的专有术语，是对这段现象的中文概括——原文直接描述为 "one feature dominates others in magnitude"，由此导致的损失曲面形状被称为 **ravine**）： $x_1$ 取值在几百量级、 $x_2$ 取值在千分之几量级，拟合 $y=x_1w_1+x_2w_2$ 时， $\partial\mathcal{L}/\partial w_1$ 比 $\partial\mathcal{L}/\partial w_2$ 大约大 $10^5$ 倍，即使两个权重本该同等调整幅度，也会导致损失曲面极度狭长。
