# 为什么"线性层 + 激活"的叠加能堆出非线性表示

> 问题：但是 hidden layer 不也是一堆线性层 + 激活的叠加吗？为啥一堆线性层能堆出非线性的表示？

事实上，一堆纯线性层是**绝对堆不出**非线性表示的。真正赋予神经网络非线性能力的“魔法”，正是穿插在这些线性层之间的**非线性激活函数**（如 ReLU、Sigmoid、Tanh 等）。

我们可以分两步来理解这个过程：

**1. 如果没有激活函数，会发生什么？（线性坍缩）**
假设我们把很多个线性层叠加在一起，不加任何激活函数。

* 第一层输出：$y_1 = W_1x + b_1$
* 第二层输出：$y_2 = W_2(y_1) + b_2 = W_2(W_1x + b_1) + b_2$
* 把括号展开合并：$y_2 = (W_2W_1)x + (W_2b_1 + b_2)$

在这个公式里，$(W_2W_1)$ 可以看作一个新的权重矩阵 $W_{new}$，$(W_2b_1 + b_2)$ 可以看作一个新的偏置 $b_{new}$。这意味着，无论你叠加 10 层还是 100 层纯线性层，它们在数学上都会“坍缩”成一个等价的单层线性模型（$W_{new}x + b_{new}$）。它依然只能画直线或平整的超平面，解决不了 XOR 这种问题。

**2. 激活函数如何打破线性？（空间折叠）**
当我们在每个线性层（矩阵乘法）之后引入一个**非线性函数**时，规则就被打破了。以最常见的 ReLU 函数 $f(x) = \max(0, x)$ 为例：

* **线性层**的作用是旋转、缩放和平移数据空间。
* **ReLU 激活**的作用是将空间中所有小于 0 的部分直接“压平”或“折叠”成 0，这是一种剧烈的非线性扭曲。

为了从数学上严谨地证明为什么这种“折叠”能打破线性坍缩，我们可以看以下推导：

**推导 A：证明 ReLU 本身违背了线性映射定义**
在线性代数中，一个函数 $T(x)$ 如果是线性的，必须严格满足“可加性”（即 $T(x + y) = T(x) + T(y)$）。
我们将 ReLU 函数 $f(x) = \max(0, x)$ 代入检验，随便取两个值，比如 $x = 1, y = -1$：

* 先相加再代入：$f(x + y) = f(1 - 1) = f(0) = 0$
* 先代入再相加：$f(x) + f(y) = f(1) + f(-1) = 1 + 0 = 1$

因为 $0 \neq 1$，即 $f(x + y) \neq f(x) + f(y)$，所以从最基础的数学定义上看，ReLU 就已经破坏了线性运算的规则。

**推导 B：证明加入 ReLU 后的网络层无法合并（构造分段线性函数）**
假设我们在刚才的两层网络中加入 ReLU，记为 $\sigma(x)$：

* 第一层（隐藏层）：$h = \sigma(W_1x + b_1)$
* 第二层（输出层）：$y = W_2h + b_2 = W_2\sigma(W_1x + b_1) + b_2$

为了证明这个最终的 $y$ 绝对不可能坍缩成一个 $W_{new}x + b_{new}$，我们用一个最简单的 1 维输入 $x$（标量）来演示。假设隐藏层有 2 个神经元：
我们人为设定第一层的权重矩阵 $W_1 = \begin{bmatrix} 1 \\ -1 \end{bmatrix}$，偏置 $b_1 = \begin{bmatrix} 0 \\ 0 \end{bmatrix}$。代入公式：


$$h = \sigma\left(\begin{bmatrix} 1 \\ -1 \end{bmatrix}x\right) = \begin{bmatrix} \max(0, x) \\ \max(0, -x) \end{bmatrix}$$

接着我们设定第二层的权重矩阵 $W_2 = \begin{bmatrix} 1 & 1 \end{bmatrix}$，偏置 $b_2 = 0$。将 $h$ 代入：


$$y = \begin{bmatrix} 1 & 1 \end{bmatrix} \begin{bmatrix} \max(0, x) \\ \max(0, -x) \end{bmatrix} = \max(0, x) + \max(0, -x)$$

我们仔细分析推导出的这个结果 $y = \max(0, x) + \max(0, -x)$：

* 当输入 $x > 0$ 时，$y = x + 0 = x$ （此时函数的斜率为 1）
* 当输入 $x < 0$ 时，$y = 0 + (-x) = -x$ （此时函数的斜率为 -1）

这就相当于我们用两层神经网络加上 ReLU，成功拟合出了一个**绝对值函数 $y = \vert{}x\vert{}$**。

现在结论就很清晰了：任何纯线性模型 $y = W_{new}x + b_{new}$，它的导数（斜率）永远是一个常数 $W_{new}$。而我们通过 ReLU 构造出的 $y = \vert{}x\vert{}$，其斜率是会发生突变的（甚至在 $x=0$ 处不可导）。**数学上不存在任何单一的矩阵 $W_{new}$ 和偏置 $b_{new}$ 能够拟合出一个斜率会发生改变的函数。**

因此，当你叠加多层“线性变换 + 非线性激活”时，就相当于在对数据空间进行“旋转拉伸 $\rightarrow$ 局部折叠 $\rightarrow$ 再旋转拉伸 $\rightarrow$ 再局部折叠”。

经过多次这样复杂的空间扭曲（像揉面团一样），原本在原始维度中相互纠缠、无法用一条直线分开的数据（比如 XOR 里的正反例），会被映射到一个高维且规则的新空间里。在这个最终的新空间 $\phi(\mathbf{x})$ 里，数据已经被“掰”成了线性可分的形态，所以最后一步只需要接一个简单的线性分类器，就能一刀切开。
