# Boosting

## 1. 基本定义

**串行**地训练一系列**弱学习器**（只比随机猜好一点，如深度为 1 的决策树"决策桩"），每个新模型重点关注前面模型**做错**的样本，最后加权组合。核心作用：**降低偏差**（也常降低方差）。

## 2. 基本流程与公式

### AdaBoost（二分类，$t \in \{-1, +1\}$）

1. 初始化样本权重 $w^{(i)} = 1/N$。
2. 对 $m = 1, \dots, M$：
   - 用权重 $w$ 训练弱学习器 $h_m$。
   - 加权错误率：
   $$\text{err}_m = \frac{\sum_i w^{(i)}\,\mathbb{I}[h_m(\mathbf{x}^{(i)}) \ne t^{(i)}]}{\sum_i w^{(i)}}$$
   - 模型权重：
   $$\alpha_m = \frac{1}{2}\ln\frac{1 - \text{err}_m}{\text{err}_m}$$
   - 更新样本权重（错的变大，对的变小），再归一化：
   $$w^{(i)} \leftarrow w^{(i)} \exp\big(-\alpha_m\, t^{(i)} h_m(\mathbf{x}^{(i)})\big)$$
3. 最终分类器：
$$H(\mathbf{x}) = \operatorname{sign}\Big(\sum_{m=1}^M \alpha_m h_m(\mathbf{x})\Big)$$

AdaBoost 等价于对**指数损失** $L(y,t)=e^{-ty}$ 做前向分步加法建模。

### Gradient Boosting（一般损失）

$$F_0(\mathbf{x}) = \text{常数}, \qquad r^{(i)}_m = -\frac{\partial L(t^{(i)}, F(\mathbf{x}^{(i)}))}{\partial F(\mathbf{x}^{(i)})}\Big|_{F=F_{m-1}}$$
用 $h_m$ 拟合残差（负梯度）$r_m$，然后
$$F_m(\mathbf{x}) = F_{m-1}(\mathbf{x}) + \eta\, h_m(\mathbf{x})$$
对平方损失，$r^{(i)} = t^{(i)} - F_{m-1}(\mathbf{x}^{(i)})$，就是普通残差。

## 3. 例子

**例 1：AdaBoost 一轮计算**
5 个样本，初始权重各 0.2。$h_1$ 错了 1 个 → $\text{err}_1 = 0.2$，$\alpha_1 = \tfrac12\ln 4 \approx 0.693$。
错的样本权重 $\times e^{0.693} = 2$，对的 $\times e^{-0.693} = 0.5$ → 未归一化 $[0.4, 0.1, 0.1, 0.1, 0.1]$，归一化后 $[0.5, 0.125, 0.125, 0.125, 0.125]$。下一轮会重点关注那个错的样本。

**例 2：Gradient Boosting 回归**
目标 $t = [3, 5, 10]$，$F_0 = \bar t = 6$，残差 $[-3, -1, 4]$。$h_1$ 拟合残差，若 $\eta = 0.1$ 且 $h_1$ 完美拟合，$F_1 = [5.7, 5.9, 6.4]$，逐步逼近目标。

**例 3：XGBoost / LightGBM / CatBoost**
工业界 Gradient Boosting 的高效实现，加入了正则化、二阶梯度、列采样等，是表格数据上最常用的强模型之一。

## 4. 什么时候用

- 基模型**高偏差**（欠拟合），如决策桩、浅树。
- **表格/结构化数据**的分类、回归、排序（Kaggle 首选之一）。
- 数据噪声不太大、可以仔细调参时。

## 5. 优缺点

**优点**
- 能把弱学习器提升为强学习器，精度通常很高。
- 同时降低偏差（和一定程度的方差）。
- Gradient Boosting 支持任意可微损失。

**缺点**
- **串行**训练，难以并行（树内部可并行）。
- 对**噪声和离群点敏感**（AdaBoost 会不断加大错误样本权重）。
- 轮数太多会**过拟合**（与 bagging 不同）。
- 超参较多（轮数、学习率、树深度）。

## 6. 注意事项

- 用**验证集 + early stopping** 决定轮数 $M$。
- **学习率 $\eta$ 与 $M$ 需权衡**：小 $\eta$ + 大 $M$ 通常更好但更慢。
- 弱学习器要"弱"：树太深会很快过拟合。
- AdaBoost 要求 $\text{err}_m < 0.5$，否则 $\alpha_m \le 0$。
- 数据标签噪声大时，考虑用更鲁棒的损失（如 Huber）或改用 bagging。
