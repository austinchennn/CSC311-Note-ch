# Learning Decision Trees — 笔记

## 一、核心定义

#### 万能函数逼近器 (universal function approximator)

**定义**：一个模型族 $\mathcal{A}$ 被称为万能函数逼近器，如果对任意连续目标函数 $f$（即任意从输入 $x$ 到输出 $t$ 的连续真实映射）、任意期望的近似误差 $\epsilon>0$（即任意程度的训练精度要求），都存在某个假设 $h\in\mathcal{A}$ ，使得对定义域内所有（或定义域中一个足够大的相关子集内所有）$x$ 都有 $\lvert h(x)-f(x)\rvert<\epsilon$ 。决策树就是一个万能函数逼近器：只要不加限制地生长，甚至可以给每个训练样本单独分配一个叶节点，从而在训练集上做到完全精确。

#### 奥卡姆剃刀 (Occam's razor)

在能解释观测数据的假设中，优先选择最简单的那个。这是一个有用但很难形式化的原则（"简单"本身如何定义并不明确），在决策树中体现为偏好更小、根节点附近就带有信息量的树。

#### 决策树中的超参数 vs 模型参数 (hyperparameters vs model parameters)

分裂用的阈值等是**模型参数**，由训练过程从数据中学出；而控制"何时停止分裂"的设置（如最大深度）是**超参数**，不是从训练数据里学出来的，而是通常用验证集经验性地调优。

#### 后剪枝 (post-pruning)

构建"有用"的树的另一种思路：先让树尽量生长（可能过拟合），再评估每个子树在验证集上的表现，把不能提升验证集表现的分支剪掉，最终保留在验证集上表现良好、结构最简单的树。

#### 决策树的归纳偏置 (inductive bias)

决策树对决策边界形式的假设：边界只能是**轴对齐**的，因此只能拼出矩形（分段轴对齐）区域。这个归纳偏置既是优点也是缺点——它带来了简单性和可解释性，但也限制了模型的表达能力（尽管理论上足够深的树可以任意逼近任意边界，因为决策树是万能函数逼近器）。

## 二、方法论

1. **贪心递归构建算法**：
   - 从根节点开始，持有全部训练数据；
   - 对每个节点：先检查是否满足停止条件（见下）——若满足，创建一个带预测值的叶节点；否则，找到能最大化信息增益的最优特征与分裂点，据此把数据分给两个子节点，并对每个子节点递归调用同样的算法；
   - 重复直到所有分支都终止于叶节点。

   这个过程之所以是递归的，是因为每棵子树本身也是一棵决策树，算法能自然处理这种层层嵌套的结构。这种贪心做法计算上高效，实践中效果也不错，但不保证得到全局最优的树——只保证每一步的分裂在局部是最优的。

2. **候选分裂的数量**：取决于特征类型。类别特征：一个二值特征只有一种划分方式；含 $k$ 个类别的特征，把它们划成两组共有 $2^{k-1}-1$ 种方式。连续特征：只需考虑相邻两个不同取值之间的分裂点——因为训练集有限，候选阈值的数量也是有限的。

3. **停止分裂的标准 (stopping criteria)**：目标是让树"不太小也不太大"——太小可能欠拟合（漏掉重要但细微的模式）；太大则计算量高、容易过拟合、也更难解释。有些情况停止分裂是显然的：若某节点是**纯的 (pure)**（节点内所有训练样本标签相同），再分裂已没有意义。更一般地，常用以下超参数控制何时停止：
   - **最大深度 (maximum depth)**：限制树能有多少层；太深容易过拟合，太浅容易欠拟合，常见取值在 3 到 20 之间（依数据集而定）。
   - **每节点最少样本数 (minimum samples per node)**：节点样本数达到某个下限才允许继续分裂，避免在极小的数据子集（更可能是噪声）上分裂。
   - **最小信息增益 (minimum information gain)**：一个分裂必须带来至少这么多的信息增益才会被采纳，达不到阈值的分裂被拒绝，防止树不必要地生长。
   - **每叶节点最少样本数 (minimum samples per leaf)**：保证每个叶节点有足够样本，样本太少（尤其带噪声时）会让该叶节点的预测不可靠。

   一个重要的背景原因是：越往树的深层走，能用的数据量会**指数级减少**——根节点用全部训练数据，但每往下一层，子节点只继承父节点数据的一个子集；到了很深的叶节点，可能只剩很少样本，预测的可靠性也随之下降。

4. **后剪枝流程**：先把树完全长大（直到拟合训练数据，可能过拟合）→ 在验证集上评估每个子树的表现 → 剪掉那些不能提升验证集表现的分支 → 保留在验证集上表现最好、结构最简单的树。

## 三、核心概念与思想

- **为什么不直接追求"最优"树**：只看训练精度的话，构建一棵"最优"树很简单——给每个训练样本单独分配一个叶节点即可做到完美的训练精度（决策树是万能函数逼近器）。但这样的树只是记住了训练集，在新数据上往往表现很差（呼应 kNN 单元里"完美训练精度不代表泛化好"的教训）；而寻找"能完美分类训练集的最小树"又是 NP-complete 问题，计算上不可行。因此实践中的目标从"绝对最优"转向学习一棵**有用 (useful)** 的树——在准确率、泛化能力、可解释性和计算效率之间取得平衡。
- **树的大小是模型容量的代理**：停止准则（如最大深度、最小分裂样本数）和后剪枝，本质上都是在控制树的大小，从而控制模型容量——这是贯穿许多 ML 模型的共同主题：超参数控制模型容量，太小欠拟合（遗漏重要模式），太大过拟合（拟合了噪声）。
- **归纳偏置的双刃剑**：决策树"决策边界必须轴对齐"这一假设，提升了可解释性、保持了模型简单，但也限制了表达能力——不过因为决策树是万能函数逼近器，理论上足够深的树仍可以任意逼近任意决策边界，只是深度带来的代价（存储、计算、过拟合风险）需要权衡。
- **训练误差可轻易降为 0（过拟陷阱，承接上一篇笔记）**：不加限制地生长，决策树可以一直分裂到每个叶节点只剩 1 个样本、或叶节点内所有样本目标值完全一致；此时无论分类树（误分类率）还是回归树（均方误差/平方误差和），训练误差都会降为 0。但这种"完美"是虚假的——它意味着模型死记硬背了训练集里的每一个噪声和离群点，在未见过的新数据上会表现得很差，这正是决策树需要停止准则与后剪枝来控制树大小的根本原因。

## 四、例子（精简保留）

- **心脏病预测两棵树对比**：树 A 只按年龄分裂——结构简单、存储少、推断快、更易解释，但可能因为过于简单而**欠拟合**、漏掉重要模式；树 B 分裂更多、叶节点更多——训练精度更高，但存储、计算、可解释性代价更高，也更可能**过拟合**。两者孰优孰劣难以一概而论，需要用合适的评估方法（如验证集）来判断，这体现了模型复杂度与泛化能力之间的核心权衡。
- **极端情况：每个训练样本单独一个叶节点**：若不加任何限制地生长，树可以为每个训练样本分配单独的叶节点，训练误差（无论是分类树的误分类率，还是回归树的均方误差/平方误差和）都会降为 0；但这只是死记硬背了训练集中的噪声与离群点，在新数据上会严重过拟合——这也是为什么需要最大深度、最小样本数等停止准则，或事后做后剪枝。
